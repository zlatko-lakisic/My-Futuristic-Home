## Flag that was built

The operator asked for one flag. On: the whole living-room TV, including DNS and time, egresses Mostar. Off: those settings disable and the TV returns to the normal New York path. That request is what authorized the routing, NAT, and firewall changes. It is not an EON-only split. `tv_over_vpn` was left empty on purpose.

### Why the rules are shaped this way

Mangle prerouting runs before dstnat. DNS and NTP have to be connection-marked while the destination is still the house resolver or a public resolver, then dstnat rewrites the destination, then the routing mark sends the connection to Mostar.

The house resolver is in New York. Tunneling a query to `HOUSE_RESOLVER_IP` does not make GeoDNS answer from Bosnia. Mostar's own DNS servers are `HOUSE_RESOLVER_IP` and `8.8.8.8`, so sending the TV at Mostar's resolver would still hit New York first. The flag rewrites the TV's port 53 to `1.1.1.1`, and that rewritten query egresses Mostar's WAN. Cloudflare then sees Mostar's public address.

`Local` on `Kuca` includes the house LAN, the Wi-Fi VLAN `192.168.90.0/24`, the perimeter, the torrent net, and the L2TP range. It does not include Mostar's LAN `192.168.88.0/24` or Mostar's ISP LAN `192.168.100.0/24`. DHCP stays local because an earlier mangle rule accepts UDP 67 and 68. Port 53 and 123 are marked before the `dst-address-list=!Local` rule, so those are hijacked even when the original destination is local. Other same-LAN traffic stays local.

Fasttrack skips mangle on later packets of an established connection. The fasttrack rule was narrowed to `connection-mark=no-mark`. Unmarked traffic, including the torrent policy route, can still fasttrack. A living-room marked connection cannot. Torrent mangle sets a routing mark only, not a connection mark. That interaction was not re-tested after the change.

If the L2TP peer stops answering ping, the distance-2 blackhole in `livingroom_over_mostar` drops the TV's marked traffic. It does not fall back to the New York WAN.

Mostar already fasttracks established/related and clamps TCP MSS (`new-mss=1300` and clamp-to-pmtu). Mostar's forward chain accepts `in-interface-list=OK-To-Route` (the L2TP interface is on that list) before `Block QUIC - force TCP fallback`. Tunneled QUIC is therefore not dropped by that rule. Mostar's main default is the ISP gateway `192.168.100.1`.

Mostar already had two disabled duplicate srcnat rules, comment `TV Filter Masquerade`, matching an empty `TV Filter List`. They were left disabled. The new rule is separate.

## TZSP listener

The first listener counted packets and parsed none. TZSP is version, type, then a uint16 encapsulated protocol (`00 01` for Ethernet), then tags through tag end `0x01`. A parser that treats byte 2 as a tag drops every frame. A captured header was `0100000101` followed by Ethernet whose destination was `LIVING_ROOM_TV_MAC`.

```python
def unwrap_tzsp(data):
    if len(data) < 5 or data[0] != 1:
        return None
    index = 4
    while index < len(data):
        tag = data[index]
        index += 1
        if tag == 1:
            return data[index:]
        if tag == 0:
            continue
        if index >= len(data):
            return None
        length = data[index]
        index += 1 + length
    return None
```

Streaming server format is `ip:port`. Restore sniffer settings from [HANDOFF.md](HANDOFF.md) when a capture ends. Router free disk was about 2.7 MiB of 16 MiB. Do not write a pcap on the router.
